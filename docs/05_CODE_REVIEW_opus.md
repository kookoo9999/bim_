## 6. 원격 기준점 정리 절차 (H-3, A-1)

### 현황
- 원격 `main`은 `3d0abd0 init commit`(2.0.6 스냅샷)에서 시작하며, 로컬 `5b01d8d`(2.0.7, tact 체크 로그)가 **원격에 없다.**
