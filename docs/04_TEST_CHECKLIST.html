2. 혼합 배열 (AABB) 티칭 & 가드 테스트

※ 조건: 1~2열 정방향(A), 3~4열 역방향(B) 자재 투입 상태에서 모델당 최초 1회 역방향 티칭 및 가드 검증

No항목(메뉴)확인 절차기대 결과판정
2-1 티칭
(정방향 기준)		 정방향 / 1열에서 정방향 ROI 및 모션 기준점 확인 TopAlignY/TopMarkY/BotMarkY 정상, Align.bmp/Align2.bmp 정상
2-2 티칭
(역방향 전환)		 역방향(180°) 라디오 클릭 → 전환 확인 캔버스 비어 있음(최초), [정방향 파라미터 복사 (+180°)] 활성화, 얼라인 썸네일 비어 있음
2-3 티칭
(열 이동)		 티칭 열을 역방향 열(3열 또는 4열) 선택 → [티칭 열 이동] 클릭 카메라가 기준점 + StripIter[k]로 이동, 화면에 역방향(180°) 스트립 경계 표시
2-4 티칭
(파라미터 복사)		 상부·하부 각각 [정방향 파라미터 복사 (+180°)] 클릭 크기·포맷·파워·스피드·Flip 복사, 각도 +180° 정규화, 좌/우(markPos) 반전 확인
2-5 티칭
(더블클릭 편집)		 역방향 캔버스에서 기존 마크 ROI 더블클릭 → 확인 후 저장 창이 열릴 때 좌/우 라디오가 역방향 기준으로 유지 (정방향으로 덮어쓰기 안 됨)
2-6 티칭
(저장 가드)		 ① Y를 0.1mm 이상 이동 후 저장 시도
② 역방향 고객 마크 Flip을 정방향과 다르게 변경 후 저장 시도		 ① "역방향 티칭 위치가 아닙니다" 경고 차단
② "정방향과 역방향의 반전 인쇄 값은 서로 다를 수 없습니다" 경고 차단
2-7 티칭
(역방향 저장)		 [티칭 열 이동]으로 정위치 복귀 → 상·하부 ROI 위치 미세 조정 → 저장 ① Backup_Reverse_* 최초 백업 폴더 생성
② DB top_r/bot_r 정상 저장 & 정방향 행 무변경
③ Align_R.bmp, Align2_R.bmp 생성 (Align.bmp 무변경)
④ Reverse.ini 기록, 정방향 기준 Y 무변경
⑤ 레이저 이중 등록 성공, 상태 역방향 상부 : OK, 하부 : OK
2-8 티칭
(복사 재실행)		 정방향 크기/각도 소폭 변경 후 역방향에서 [정방향 파라미터 복사] 재클릭 기존 역방향 ROI 중심 유지한 채 크기·미리보기 각도 갱신
2-9 티칭
(취소 원복)		 역방향에서 ROI 임의 이동/추가 후 저장 없이 [취소] → 티칭 창 재진입 정방향 화면·뱅크 0 썸네일 복원, 역방향 전환 시 미저장 변경 원복 확인
2-10 티칭
(Stale 감지)		 정방향 Y를 0.1mm 이상 옮겨 정방향 저장 → Lot 입력 진입 (확인 후 원위치 재저장) "정방향 기준점이 변경되었습니다…" 경고, 상태 재티칭 필요, LotWindow 역방향 토글 비활성화 + 사유 툴팁
2-11 티칭
(초기화 격리)		 (선택) 역방향 화면에서 [초기화] 실행 (확인 후 역방향 재티칭) top_r/bot_r, Align_R/2_R.bmp, 화면 썸네일만 삭제. 정방향 DB·템플릿 100% 보존
2-12 가드
(미지원 옵션)		 UseAOIMark=true 또는 MakringShiftCheck=true 모델에서 LotWindow 진입 역방향 토글 비활성화 + 툴팁에 미지원 사유 표시 (강제 시작 불가)

3. 혼합 배열 (AABB) 자동시작 — 얼라인 · 마킹 품질 · 비전 검사

※ 조건: 2절 역방향 티칭 완료 후 실제 AABB 자재(1~2열 정방향, 3~4열 역방향) 투입

No항목(메뉴)확인 절차기대 결과판정
3-1 Lot 입력 LotWindow에서 A·B=정방향, C·D=역방향 토글 후 확인 차단 없이 통과. (템플릿 누락 등 차단 후 창 닫기 시 전역 orients 미오염)
3-2 마킹정보 확인 WorkMarkInfoWindow 확인 (A열) 정, (B열) 정, (C열) 역, (D열) 역 표시. 역방향 열 ID가 좌/우 스왑 규칙대로 계산됨
3-3 자동시작
(첫 사이클 얼라인)		 stripID=2 (RightOnly) 얼라인 실행 및 로그 확인 1열(정) 2번 ↔ 4열(역) 1번(화면 우측) 매칭 성공.
로그: [Align] 정/역 혼합 베이스라인 보정 : +X.XXXX mm — 반드시 양수(+)
3-4 자동시작
(일반 얼라인)		 stripID>=3 (MarkingAlignToROI) 연속 실행 1열(정) 얼라인1 ↔ 4열(역) 좌측 얼라인2 매칭 성공, 보정값 양수(+) 유지, 1~4열 기울기 보정 정밀도 정상
3-5 자동시작
(마킹 품질)		 상·하부 1~4열 연속 마킹 후 실물 육안/현미경 확인 ① 1~2열(0~), 3~4열(20~)만 각인 — 이중 각인 없음
② 3~4열(역) 180° 회전 방향·위치·크기·선명도가 1~2열(정) 및 기존 AAAA와 동등한 품질
③ Laser 로그: C1~2 정(0~), C3~4 역(20~) 및 위치 스왑 기록
3-6 실물 ID 교차검증 시작번호 2로 4~5사이클 마킹 후 스트립 1~4번을 4개 열 모두 스캔 ① 1번(폐기): 한쪽 끝만 0001
② 2번(양품): 1~2열(정) · 3~4열(역) 4열 모두 양 끝(사내1·고객1) 0002 일치
③ 3번(양품): 4열 모두 양 끝 0003 일치
④ 마지막 N(폐기): 한쪽 끝만 000N
3-7 자동시작
(첫 사이클 검사)		 stripID=2 마킹 직후 RunMarkCheck 알람 여부 확인 현장 집중 확인 역방향 열(3~4열) 고객1은 폐기 strip(좌측)에 각인됨 → 기판 부재로 COGNITION_FAIL 알람 발생 여부 기록
3-8 자동시작
(비전 디코딩)		 stripID>=3 상·하부 1~4열 비전 검사 및 저장 이미지 확인 ① 1~2열(정) & 3~4열(역, 180°) 상·하부 디코딩 성공 (폴백 알고리즘 포함)
② 3~4열 저장 .jpg 파일명의 lot(lots[2..3]) & strip 번호가 실물과 일치
3-9 모델관리
(모델 전환)		 AABB 테스트 후 다른 모델 선택 → LotWindow 진입 이전 AABB가 남지 않고 4열 전부 정방향으로 초기화됨

※ (선택) BBAA 시편 테스트 가능 시: 1~2사이클 실행해 베이스라인 보정 로그가 음수(-)로 출력되는지 추가 확인

4. ITS · DB · 정지/이어하기 · EOL 공통 테스트 (AAAA / AABB 각각 수행)

4-1 ITS / DB
(매 사이클 기록)		 시작번호 2로 S=2, 3, 4 진행 후 4열 ITS(.lmh, temp) & DB work_history 확인 ① S=2→ITS 0001, DB FirstID=2, StripID=1

4-2 일시정지 →
이어하기		 0003 기록·피딩 후 일시정지(STOP) → 자동시작 재실행 (WorkHistoryWindow) ① 시작 번호 5(3 + 2) 자동 세팅
② 팝업: (ITS 마지막 완성 strip : 3 → 이번 사이클 완성 strip : 4) 표시
③ 재개 후 ITS 0004 연속 기록, DB FirstID=2 유지
4-3 ITS 중복 차단 0004 기록 상태에서 수동으로 기준 번호 5(완성 0004) 입력 시도 ITSHistoryWindow에서 lots[0] + " 0004" 중복 감지 → OVERLAP_MARKING 즉시 차단

(EOL)		 이어하기 후 1~2사이클 추가 진행 → 작업 완료(WorkEndWindow) 후 4열 ITS·ITS(temp) 확인 ① 첫 사이클 임시 기록 0001 행 삭제 (정식·temp 양쪽)
② 최종 내용: 0002 ~ 000(N-1) + EOL (양품만 남음)
